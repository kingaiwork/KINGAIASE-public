## Accessibility / truthful publication

- Human-readable navigation labels and keyboard-visible focus rings.
- Responsive link wrapping, no horizontal overflow, reduced-motion support.
- Product websites must not promise general availability where only Developer Preview, Pre-Alpha, Public Beta or Production Candidate is verified.
- A committed repository change is not proof of a live deployment: verify CI, public content, build and real-domain smoke before marking a release as deployed.
- Keep all private code, provider values, internal network topology, sensitive evidence and identity authority outside the public hub.

## Public repository boundaries

The public hub contains approved descriptions and links, never mirrored private source. Public delivery repositories remain explicitly separate when security or sanitization requires that boundary. Public GitHub repositories are not the same as production services.
