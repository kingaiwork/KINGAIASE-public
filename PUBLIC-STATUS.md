# KING AI — Public Product Status Guide

**Last public review:** 2026-08-20  
**Canonical platform:** https://www.kingai.work/

This file exists to prevent roadmap language, repository activity or screenshots from being mistaken for verified customer availability.

## Status vocabulary

### Available / public product surface
A user-facing public surface exists. This does not automatically mean every feature, platform or commercial package is generally available.

### Production candidate / candidate
A product line has reached a validation stage intended for production readiness, but additional signing, device, store, operational or release gates may remain.

### In development
The product direction is actively being built. It should not be sold or described as universally finished.

### Pre-Alpha
An early product stage. Intended direction can be discussed, but production expectations must remain conservative.

### Roadmap
A future direction only.

### Legacy public repository
A historical/discovery repository. It is not a current source, installation or release authority.

## Status integrity rules

1. Repository activity is not customer availability.
2. A successful build is not automatically a stable release.
3. A roadmap is not a released capability.
4. A public website can describe direction, but production scope must still be verified.
5. Historical screenshots, releases and cached pages do not override current status.
6. Product status must not be inflated for marketing or investment presentation.

## Core implementation remains private

This status guide deliberately omits proprietary implementation, private architecture, credentials, model configuration, prompts, database design, security internals and production topology.
