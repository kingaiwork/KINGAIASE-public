# Page Template
Every important landing page should include:
1. one clear canonical definition
2. user problem
3. KING AI SEA mission model
4. capability/workforce pattern
5. high-level public architecture
6. trust/permission boundary
7. representative use cases
8. integrations/deployment context
9. FAQ
10. related internal links
11. clear CTA
12. truthful capability status
