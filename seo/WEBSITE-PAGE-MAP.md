# Technical Implementation Rules

For every production page:

- unique `<title>`
- unique meta description
- one clear H1
- canonical URL
- explicit language
- correct hreflang links between equivalent translations
- descriptive internal anchors
- crawlable primary content
- Open Graph metadata
- relevant structured data that matches visible content
- breadcrumb navigation for deeper pages
- inclusion in XML sitemap if indexable
- no accidental `noindex`
- stable URL whenever possible

The website should link back to the official GitHub documentation where useful, while the GitHub repository should link to the canonical product pages on kingai.work.
