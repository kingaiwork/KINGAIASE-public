## Homepage Data Semantics

KING AI public homepage data has three explicit modes:

1. **LIVE DATA** — current verified public snapshot.
2. **VERIFIED CACHE** — previously verified snapshot that remains within the allowed cache window.
3. **DEMO DATA** — presentation-only fallback when no trustworthy live or cached snapshot exists.

Demo data is not a factual claim about real countries, companies, people or incidents and is not eligible for automated action.

## Public / Private Boundary

Public GitHub repositories may be synchronized into the KING AI Project Registry using sanitized repository metadata, README content and public release information.

Private repositories are not public data sources by default. Production source code, credentials, private endpoints, customer information, private deployment topology and security-sensitive implementation details are not part of the public knowledge graph.
