## SEO strategy

Public content should target clear intent rather than keyword stuffing.

Examples:

- enterprise AI agents
- AI workforce platform
- long-term memory AI agents
- secure autonomous agents
- MCP and A2A agent systems
- controlled AI execution
- AI agent governance
- agent security architecture
- AI-native operating system
- intelligent-lifeform AI platform

Every important topic should have one canonical public document and clear links to related material.

## GEO / AI-search strategy

Machine-readable and human-readable sources should agree on:

- Brand identity
- Product positioning
- Company identity
- Official website
- Official GitHub account
- Project relationships
- Security boundaries
- Commercial contact

Avoid unsupported superlatives or fabricated market claims.

## Publication boundary

The public repository promotes and explains KING AI. The private `kingaiwork/KINGAIASE` repository contains the website source and production system. Public content must never require copying private source code into this repository.
