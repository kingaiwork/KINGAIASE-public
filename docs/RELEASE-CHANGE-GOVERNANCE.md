# 🚀 KING AI SEA — Release & Change Governance

# English

## Change Classes
- documentation/content
- prompt/configuration
- role permission
- integration
- workflow/mission
- model/provider
- infrastructure
- security policy
- database/data transformation

## Change Control
For material production changes document: reason, owner, affected missions, risk, test evidence, approval, deployment plan, rollback, monitoring and post-change review.

## High-Risk Changes
Permission expansion, privileged integrations, destructive actions, identity/security policy and production data transformations require stronger approval.

# 中文
变更类别包括文档、Prompt/配置、岗位权限、集成、Mission/工作流、模型/供应商、基础设施、安全策略和数据库/数据转换。

重要生产变更必须记录原因、负责人、受影响 Mission、风险、测试证据、审批、部署、回滚、监控和变更后复核。

权限扩张、特权集成、破坏性动作、身份/安全策略和生产数据转换属于更高风险变更。
