# 🧾 KING AI SEA — Enterprise Procurement Checklist

# English
Before contract/sign-off, verify:

## Business
- executive sponsor
- mission owners
- defined outcomes
- baseline metrics
- scope and exclusions

## Technical
- required integrations
- environments
- deployment model
- identity/access
- data sources
- logging/observability

## Security
- questionnaire reviewed
- secrets ownership
- permission model
- approval model
- incident path
- human override

## Commercial
- implementation scope
- recurring scope
- support scope
- usage assumptions
- custom work
- change requests
- renewal/termination terms

## Delivery
- RACI
- timeline/milestones
- acceptance criteria
- pilot gate
- production gate
- training
- support handoff

# 中文
采购签署前确认五类事项：

**业务：** Sponsor、Mission Owner、结果、基线、范围/排除项。  
**技术：** 集成、环境、部署、身份、数据、日志。  
**安全：** 安全问卷、密钥、权限、审批、事件、人类接管。  
**商业：** 实施、周期服务、支持、使用假设、定制、变更、续约/终止。  
**交付：** RACI、里程碑、验收、Pilot Gate、Production Gate、培训和支持移交。
