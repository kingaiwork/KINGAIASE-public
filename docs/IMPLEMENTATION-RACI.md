# 👥 KING AI SEA — Implementation RACI

# English

| Workstream | Customer Executive | Mission Owner | IT/Security | KING AI Solution Team | Business Users |
|---|---|---|---|---|---|
| Business outcome | A | R | C | C | C |
| Mission design | C | A/R | C | R | C |
| Data approval | C | A | R | C | C |
| Integration access | I | C | A/R | R | I |
| Security review | I | C | A/R | R | I |
| Role/permission design | C | A | R | R | C |
| Pilot testing | I | A | C | R | R |
| Acceptance | A | R | C | C | C |
| Production operations | I | A | R | R | C |
| KPI review | A | R | C | C | C |

A = Accountable, R = Responsible, C = Consulted, I = Informed.

# 中文
实施必须明确责任，而不是让“AI 项目”成为无人负责的跨部门任务。

建议至少区分：客户高管 Sponsor、Mission Owner、IT/安全、KING AI Solution Team 和业务用户，并对业务结果、Mission、数据、集成、安全、权限、Pilot、验收、生产运维和 KPI 设置 A/R/C/I。
