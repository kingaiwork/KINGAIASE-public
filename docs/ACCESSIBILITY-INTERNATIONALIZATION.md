# 🌐 KING AI SEA — Accessibility & Internationalization

# English

## Internationalization
Plan for language, locale, timezone, date/number formats, currency, writing direction where relevant, regional terminology and human escalation coverage.

## Content Rules
- English canonical global version
- complete Chinese version
- avoid mixed-language SEO pages
- preserve entity meaning across languages
- add new languages only with quality review

## Accessibility
Digital experiences should target semantic structure, keyboard usability, readable contrast, labels, alt text, understandable error messages and mobile responsiveness.

# 中文
国际化需要考虑语言、Locale、时区、日期/数字、货币、必要时的文字方向、地区术语和人工升级覆盖。

英文为全球标准版本，中文提供完整独立版本；避免中英混杂 SEO 页面；跨语言必须保持同一品牌实体含义；新增语言需要质量审核。

数字体验应重视语义结构、键盘可用、对比度、标签、Alt Text、可理解错误提示和移动端适配。
