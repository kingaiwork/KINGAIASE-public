# KING AI Public Language Policy

## English

All public repositories and public-facing repository content in this workspace use **English first, Simplified Chinese second** by default.

This applies to README files, product overviews, business/partnership material, public roadmaps, SEO/GEO pages, AI-readable files, public FAQs and customer-safe knowledge.

When both languages are in one file, publish the complete English section first, then the complete Simplified Chinese section. When separate files are used, English remains the default entry and links clearly to Chinese; Chinese links back to English.

This language rule does not change project ownership. Jackhao.tv, USChinese/美国华人网, ZuiMeiTV/最美TV and Atalk.TV remain founder personal projects and are not KING AI ecosystem products.

# 中文

本工作区所有公开仓和公开资料默认统一采用：**英文在前，简体中文在后**。

该规则适用于 README、产品介绍、商业/合作资料、公开路线图、SEO/GEO、AI 可读文件、公开 FAQ 和客服安全知识。

如果中英文写在同一个文件中，应先发布完整英文内容，再发布完整简体中文内容；如果使用独立语言文件，则英文作为默认入口，并清晰链接中文版本，中文版本也应链接回英文。

语言规则不改变项目归属：Jackhao.tv、USChinese/美国华人网、ZuiMeiTV/最美TV、Atalk.TV 永久保持创始人个人项目身份，不属于 KING AI 主生态。
