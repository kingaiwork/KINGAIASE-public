# 🛡️ KING AI SEA · Security Positioning

# ✦ ENGLISH

KING AI SEA is designed around **user-controlled automation and permission boundaries**.

## Public Principles
- Users define the automation scope.
- Organizations define execution permissions.
- Sensitive actions can require explicit approval.
- Activity can be reviewed and governed.
- Private deployment can be used where required.
- Different roles can receive different levels of access.

## Proprietary Protection
Internal security architecture, privileged control mechanisms, private policy logic, model-control rules, memory implementation and other proprietary mechanisms are not disclosed in this public repository.

# ✦ 中文

KING AI SEA 围绕 **使用者可控的自动化范围、执行权限与安全边界** 进行设计。

## 对外安全原则
- 自动化范围由使用者设定。
- 企业可以定义不同的执行权限。
- 敏感操作可以要求明确批准。
- 关键活动可以被审查与治理。
- 有需要时可采用私有部署环境。
- 不同角色可以拥有不同级别的访问权限。

## 核心技术保护
内部安全架构、高权限控制机制、私有策略逻辑、模型控制规则、记忆实现及其他专有机制不会在本公开仓库中披露。
