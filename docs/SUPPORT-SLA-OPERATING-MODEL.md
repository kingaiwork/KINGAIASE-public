# 🛠️ KING AI SEA — Support & SLA Operating Model

> Framework only. Actual SLA commitments belong in customer agreements.

# English

## Support Layers
- Product guidance
- Integration support
- Deployment operations
- Incident support
- Security escalation
- Enterprise success / architecture review

## Severity Model Example
- P1 Critical — material production outage/security-impacting condition
- P2 High — major feature/workflow degradation
- P3 Normal — limited issue or non-critical defect
- P4 Request — question, enhancement or planned change

## Required Operational Data
For every incident capture: customer/environment, mission, role, integration, start time, impact, workaround, owner, status, resolution and follow-up test.

## SLA Integrity
Do not publish response or uptime commitments until operational capacity and contract language support them.

# 中文
支持可分产品指导、集成、部署运维、事件、安全升级和企业成功/架构评审。

可使用 P1-P4 严重度模型，但真正响应时间和可用性 SLA 只有在运营能力和合同正式支持时才能公开。
