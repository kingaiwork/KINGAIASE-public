# 📚 KING AI SEA — Knowledge Operations Standard

# English

## Knowledge Lifecycle
Source → Approve → Ingest/Connect → Organize → Use → Observe gaps → Update → Retire.

## Required Metadata
- source owner
- authority level
- effective date
- review date
- audience/role scope
- mission scope
- confidentiality class
- canonical URL/location

## Quality Controls
Detect stale pages, contradictions, duplicate policies, missing owners, broken links and unsupported claims.

## Answerability
For important business questions, identify a canonical answer source instead of allowing multiple conflicting documents to compete.

# 中文
知识生命周期：来源 → 批准 → 接入 → 整理 → 使用 → 发现缺口 → 更新 → 退役。

关键知识应包含负责人、权威等级、生效日期、复核日期、岗位/Mission 范围、保密等级和标准位置。

持续检查过期、冲突、重复、无人负责、坏链和无证据声称。重要业务问题应指定标准答案源，避免多个互相冲突文档同时作为真相。
