# 📋 KING AI SEA — Enterprise Readiness Scorecard

# English
Score each 0–3: 0 absent, 1 early, 2 workable, 3 strong.

## Business Readiness
- clear mission
- executive sponsor
- process owner
- measurable baseline

## Data Readiness
- authoritative sources
- data owner
- acceptable quality
- approved access

## Integration Readiness
- APIs/tools available
- environment access
- credentials ownership
- failure behavior understood

## Governance Readiness
- role model
- approval model
- incident owner
- human override

## Evaluation Readiness
- test cases
- KPI
- acceptance threshold
- review cadence

## Adoption Readiness
- user group identified
- training path
- communication plan
- feedback loop

**Interpretation:** low scores indicate that expanding autonomy is premature; focus first on mission clarity, data, governance and observability.

# 中文
每项 0–3 分：0 缺失、1 初期、2 可用、3 较强。

六类：业务就绪、数据就绪、集成就绪、治理就绪、评估就绪、采用就绪。

低分不代表不能用 AI，而是表示不应过早扩大自主权，应先补 Mission 清晰度、数据、治理和可观测能力。
