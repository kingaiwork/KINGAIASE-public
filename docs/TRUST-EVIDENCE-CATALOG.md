# 🧾 KING AI SEA — Trust Evidence Catalog

# English
Enterprise trust should be supported by evidence artifacts, not only statements.

## Evidence Categories
1. architecture overview
2. role/permission matrix
3. mission inventory
4. integration inventory
5. data-source inventory
6. approval rules
7. audit/action history samples
8. evaluation scorecards
9. incident process
10. human override procedure
11. environment separation
12. secret/credential ownership policy
13. change-control history
14. access-review evidence
15. backup/recovery documentation where applicable
16. product-status matrix
17. known limitations
18. pilot acceptance results

## Disclosure Boundary
Provide enough evidence for customer assurance while withholding exploit-enabling security logic, credentials and proprietary implementation.

# 中文
企业信任应由“证据包”支持，而不只是宣传。

可准备：公开架构、权限矩阵、Mission 清单、集成/数据源清单、审批规则、审计样本、评估、事件流程、人类接管、环境隔离、密钥所有权、变更记录、访问复核、备份恢复、产品状态、已知限制和 Pilot 验收结果。

对客户提供足够的治理证据，同时不披露可被利用的安全逻辑、凭据或核心实现。
