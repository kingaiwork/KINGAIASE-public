# 👔 KING AI SEA — AI Employee Role Design Standard

# English
An AI Employee role is more than a prompt.

## Required Role Profile
- Role name
- Business purpose
- Human manager / owner
- Mission types
- Knowledge scope
- Tool scope
- Action permissions
- Approval rules
- Escalation rules
- Communication channels
- KPI
- Quality tests
- Prohibited actions
- Environment / deployment scope

## Role Principles
- least privilege
- clear mission boundaries
- evidence-based expansion
- human accountability
- explicit prohibited actions
- measurable outcomes
- separable development/staging/production scope

## Role Lifecycle
Design → Test → Pilot → Approve → Operate → Evaluate → Adjust → Retire/Expand.

# 中文
AI 员工不是“一个 Prompt”。生产级岗位必须拥有角色名称、业务目的、人工负责人、Mission 类型、知识范围、工具范围、行动权限、审批、升级、沟通渠道、KPI、测试、禁止动作和环境范围。

核心原则：最小权限、明确边界、基于证据扩权、人类最终责任、显式禁止动作、可衡量结果、开发/测试/生产可分离。

生命周期：设计 → 测试 → Pilot → 批准 → 运营 → 评估 → 调整 → 退出或扩展。
