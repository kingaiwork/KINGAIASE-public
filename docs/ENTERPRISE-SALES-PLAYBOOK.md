# 💼 KING AI SEA — Enterprise Sales Playbook

# English

## Discovery Sequence
1. What business outcome matters?
2. Which workflow currently causes cost/delay/risk?
3. Who owns it?
4. What systems/data are involved?
5. What action can AI safely take?
6. What requires approval?
7. What KPI proves value?
8. What deployment/security requirements exist?

## Sell the Mission, Not the Model
Avoid leading with model names or raw token specifications. Position around persistent intelligence, governed action, AI Workforce, measurable missions and integration with the customer's real operating environment.

## Enterprise Path
Discovery → Architecture Assessment → Pilot → Acceptance → Production → Expansion.

## No Fake Proof
Do not invent customers, benchmarks or savings. Use architecture quality, demo evidence, pilot metrics and approved case studies.

# 中文
企业销售首先问业务结果，不先卖模型。

顺序：结果 → 当前流程问题 → 负责人 → 数据/系统 → AI 可安全执行什么 → 什么要审批 → KPI → 部署/安全要求。

企业路径：Discovery → 架构评估 → Pilot → 验收 → 生产 → 扩展。

禁止虚构客户、Benchmark 或节省比例，使用真实架构、Demo、Pilot 指标和经过批准的案例建立可信度。
