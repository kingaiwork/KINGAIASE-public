# 🧭 KING AI SEA — Responsible Deployment Standard

# English

## Core Rule
Capability must be matched by authority, evidence and human accountability.

## Required Safeguards
- defined mission
- scoped data/tools
- least privilege
- approval for high-impact actions
- explicit prohibited actions
- human escalation/override
- logs and evaluation
- staged rollout
- incident pause/disable controls

## Higher-Risk Domains
For healthcare, finance, employment, legal, public administration, safety-critical infrastructure and other regulated/high-impact areas, AI should support authorized workflows without representing unverified autonomous professional judgment.

## Autonomy Ladder
Observe → Recommend → Draft → Execute bounded low-risk action → Execute with approval → Restricted human-only.

# 中文
核心原则：能力必须与权限、证据和人类责任匹配。

正式部署必须有 Mission、数据/工具范围、最小权限、高影响审批、禁止动作、人类升级/接管、日志评估、分阶段上线和暂停/禁用控制。

医疗、金融、就业、法律、公共行政、安全关键基础设施等高影响领域，应辅助授权流程，不应把未经验证的自主专业判断包装成自动决策。

自主等级：观察 → 建议 → 草稿 → 边界内低风险执行 → 审批后执行 → 人工专属。
