# English

## Status Labels

- **Available** — usable in the current supported product / deployment scope.
- **Custom-by-Scope** — deliverable through a defined project or integration scope.
- **In Development** — actively being built or validated.
- **Planned** — committed product direction but not yet available.
- **Vision** — long-term direction, not a current commitment.
- **Retired** — no longer positioned as active.

# 中文

统一状态标签：

- **已可用 Available**
- **按项目范围定制 Custom-by-Scope**
- **开发中 In Development**
- **规划中 Planned**
- **长期愿景 Vision**
- **已停止 Retired**

所有官网、GitHub、销售材料和 AI 可读数据必须引用同一个真实状态，不允许因为路线图里出现过某功能就自动写成“已经上线”。

本文件只提供状态治理模板，具体状态由产品负责人实际核验。
