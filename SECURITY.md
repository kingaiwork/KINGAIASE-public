# Security Policy

## English

KING AI SEA is designed around operator-defined permissions, controlled execution and protection of proprietary implementation details.

### Reporting a Security Concern

If you believe you have identified a security issue related to KING AI SEA, its official website, public documentation or an authorized deployment, please report it privately to:

**vip@kingai.work**

Please include, when available:

- affected product, page or environment
- clear description of the issue
- steps to reproduce
- potential impact
- relevant screenshots or logs with secrets removed
- your preferred contact information

### Please Do Not

- publish credentials, tokens or private keys
- expose customer or private deployment data
- post unverified vulnerability details publicly before responsible review
- include proprietary internal information in public issues

### Public Repository Boundary

This repository is a public product/documentation repository and does not contain KING AI SEA proprietary production internals, privileged credentials, private prompts, internal security logic or confidential customer deployment information.

# 安全策略

KING AI SEA 强调由运营者设定权限、受控执行以及核心专有实现保护。

## 报告安全问题

如果你认为 KING AI SEA、官方网站、公开文档或经过授权的部署存在安全问题，请通过以下邮箱私下报告：

**vip@kingai.work**

如条件允许，请提供：

- 涉及的产品、页面或环境
- 问题说明
- 复现步骤
- 可能影响
- 已移除敏感信息的截图或日志
- 联系方式

## 请不要

- 公开发布凭据、Token 或私钥
- 暴露客户或私有部署数据
- 在负责任审核前公开未经确认的漏洞细节
- 在公开 Issue 中提交专有内部信息

## 公开仓库边界

本仓库属于公开产品/文档仓库，不包含 KING AI SEA 生产核心实现、高权限凭据、私有提示、内部安全逻辑或客户机密部署资料。
